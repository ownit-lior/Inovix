# INOVIX — Hebrew RTL Landing Page

Luxury smart-home marketing site with Framer Motion scroll/parallax effects.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- Tailwind CSS
- Framer Motion
- Heebo (Hebrew) via `next/font`

## Sections

1. Fixed RTL navbar
2. Parallax hero
3. Staggered features grid
4. Dark 3D showroom placeholder (`#threejs-container`)
5. Testimonials carousel
6. Contact lead form
7. Footer
