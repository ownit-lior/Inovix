## העלאה ל־WordPress
1. Media → Add New → העלה את כל תוכן הזיפ (או את התיקיות).
2. Site Settings → Design → Global Colors לפי הפלטה למעלה.
3. Theme Builder: Header + Footer קבועים.
4. צור עמודים לפי הרשימה למטה (עברית, RTL).
